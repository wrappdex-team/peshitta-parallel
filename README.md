# Peshitta Parallel

A reader for the Syriac Peshitta New Testament, set beside James Murdock’s 1852 English.

The Syriac is the Peshitta (with the later books marked). The English is Murdock’s public-domain translation. Study notes sit on selected verses and explain the wording; they are not a second translation.

## Run locally

```bash
npm install
npm run dev
```

Open the app at `http://localhost:8080`.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run typecheck` — TypeScript check
